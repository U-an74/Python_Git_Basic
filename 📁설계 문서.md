## 2. 기초 설계 - CRUD/종료 구현

- 모든 프로그램의 기본이 되는 **CRUD**(Create, Read, Update, Delete)와 종료 기능을 우선 구현하여 전체 프로그램의 뼈대가 되는 초안 코드를 작성한다.
- 생성(C)/종료 기능 구현
    
    <aside>
        
    **💡구현 포인트**
    
    1. `def`를 활용해 각 기능 별로 함수를 분리하여 설계 
    2. `while True`를 활용해 종료를 누르기 전까지는 프로그램 실행이 유지되도록 루프 설정
    </aside>
    
    ```jsx
    # 1. 데이터 저장소
    prompts = []
    
    # 2. 메뉴 출력 함수
    def show_menu():
        print("\n--- 프롬프트 매니저 ---")
        print("1. 프롬프트 추가")
        print("2. 종료")
        
    # 3. 메인 실행부
    def main():
        while True:
            show_menu()
            choice = input("메뉴 선택: ")
            if choice == "1":
                title = input("제목: ")
                # 1. 제목 입력 후 내용을 입력받는 줄을 추가합니다.
                content = input("내용: ") 
                # 2. 딕셔너리에 제목, 내용을 함께 저장합니다.
                prompts.append({"title": title, "content": content}) 
                print(f"'{title}'프롬프트가 저장되었습니다.")
            elif choice == "2":
                print("프로그램을 종료합니다.")
                break # while 반복문을 빠져나갑니다.
                
    if __name__ == "__main__":
        main()
    ```
    
- 목록(R)/수정(U)/삭제(D) 기능 구현
    
    <aside>
        
    **💡구현 포인트**
    
    1. 전체 함수 구조 정리: `prompts = []`를 `while`문 바로 위에 두어 실행중 데이터 유지
    2. (2)목록 구성시 `enumerate` 를 활용하여 편리하게 리스트 앞에 번호 붙임
    3. (3)수정/(4)삭제 대상 번호를 사용자가 입력하면, 자동으로 1을 빼서 리스트 인덱스 변경 
     (`idx = int(...) - 1`)
    4.  생성된`[idx]`를 활용해 해당 데이터를 고치거나(`input`) 지움(`pop`).
    </aside>
    
    ```jsx
    # 1. 메뉴 출력
    def show_menu():
        print("\n--- 프롬프트 매니저 ---")
        print("1. 프롬프트 추가_C")
        print("2. 프롬프트 목록_R")
        print("3. 프롬프트 수정_U")
        print("4. 프롬프트 삭제_D")
        print("5. 종료")
    
    # 2. 메인 실행부
    def main():
        prompts = []  # 데이터 저장소 
    
        while True:
            show_menu()
            choice = input("메뉴 선택: ")
    
            if choice == "1":  # CREATE (프롬프트 추가)
                title = input("제목: ")
                content = input("내용: ") 
                prompts.append({"title": title, "content": content}) 
                print(f"'{title}' 프롬프트가 저장되었습니다.")
    
            elif choice == "2":  # READ (프롬프트 목록)
                print("\n--- 현재 목록 ---")
                for i, p in enumerate(prompts):
                    # i(컴퓨터가 세는 번호)는 0부터 시작, 사용자에게는 i+1로 표시
                    # p(해당 번호에 들어 있는 실제 데이터 = 딕셔너리)
                    print(f"{i+1}. {p['title']}")
    
            elif choice == "3":  # UPDATE (프롬프트 수정)
                idx = int(input("수정할 번호: ")) - 1
                if 0 <= idx < len(prompts):
                    prompts[idx]['title'] = input("새 제목: ")
                    prompts[idx]['content'] = input("새 내용: ")
                    print("수정되었습니다!")
                else:
                    print("없는 번호입니다.")
    
            elif choice == "4":  # DELETE (프롬프트 삭제)
                idx = int(input("삭제할 번호: ")) - 1
                if 0 <= idx < len(prompts):
                    deleted = prompts.pop(idx)
                    print(f"'{deleted['title']}'이 삭제되었습니다.")
                else:
                    print("없는 번호입니다.")
    
            elif choice == "5":  # 종료
                print("프로그램을 종료합니다.")
                break 
    
    if __name__ == "__main__":
        main()
    ```

## 3. 심화 설계 - 기능 요구 사항 반영 추가 구현

- 기능 요구 사항을 체크리스트화하여 재확인하는 방법으로 프로그램의 디테일을 보완하고 완성한다. 
(기능 추가 완료 시 ✅표시)
- 3. 에서 이미 진행한 기초 설계이거나, 심화 설계 각 단계에서 이미 구현이 완료된 기능은 소거 및 ☑️표시하고 별도 설명은 중복이므로 생략한다.
- 프로그램 실행 및 메뉴
    - [x]  사용자가 번호를 입력하여 기능을 선택한다.
    - [x]  프로그램 실행 시 메뉴가 출력되어야 한다.
    
     ✅ 잘못된 번호 입력 시 안내 메시지를 출력하고 다시 메뉴를 보여준다.
    
    <aside>
    💡
    
    **구현 포인트**
    
    1. `main()` 함수의 메뉴 **분기문(`if ~ elif` 구조)의 마지막에 `else` 추가**
        - `1~5`가 아닌 입력이 들어오면 경고 메시지를 출력
        - `while True` 구조이므로 메시지 출력 후 자동으로 루프(다시 메뉴 표시)
    </aside>

        ```jsx
        # 1. 메뉴 출력
        def show_menu():
            print("\n--- 프롬프트 매니저 ---")
            print("1. 프롬프트 추가_C")
            print("2. 프롬프트 목록_R")
            print("3. 프롬프트 수정_U")
            print("4. 프롬프트 삭제_D")
            print("5. 종료")
        
        # 입력값 누락 방지
        def get_non_empty_input(prompt):
            while True:
                value = input(prompt).strip()
                if value:
                    return value
                print("값이 비어 있습니다. 다시 입력해주세요.")
        
        # 카테고리 선택
        def select_category():
            preset_categories = ["텍스트 생성", "멀티모달 생성", "기타"]
        
            while True:
                print("\n--- 카테고리 선택 ---")
                for i, category in enumerate(preset_categories):
                    print(f"{i+1}. {category}")
                print(f"{len(preset_categories)+1}. 직접 입력")
        
                choice = input("선택: ").strip()
        
                if choice.isdigit():
                    num = int(choice)
        
                    if 1 <= num <= len(preset_categories):
                        return preset_categories[num - 1]
                    elif num == len(preset_categories) + 1:
                        return get_non_empty_input("카테고리 직접 입력: ")
        
                print("잘못된 선택입니다. 다시 선택해주세요.")
        
        # 2. 메인 실행부
        def main():
            prompts = []  # 데이터 저장소 
        
            while True:
                show_menu()
                choice = input("메뉴 선택: ")
        
                if choice == "1":  # CREATE (프롬프트 추가)
                    title = get_non_empty_input("제목: ")
                    content = get_non_empty_input("내용: ")
                    category = select_category()
        
                    prompts.append({
                        "title": title,
                        "content": content,
                        "category": category,
                        "favorite": False
                    })
        
                    print(f"'{title}' 프롬프트가 저장되었습니다.")
        
                elif choice == "2":  # READ (프롬프트 목록)
                    print("\n--- 현재 목록 ---")
                    for i, p in enumerate(prompts):
                        print(f"{i+1}. {p['title']} [{p['category']}]")
        
                elif choice == "3":  # UPDATE (프롬프트 수정)
                    idx = int(input("수정할 번호: ")) - 1
                    if 0 <= idx < len(prompts):
                        prompts[idx]['title'] = input("새 제목: ")
                        prompts[idx]['content'] = input("새 내용: ")
                        print("수정되었습니다!")
                    else:
                        print("없는 번호입니다.")
        
                elif choice == "4":  # DELETE (프롬프트 삭제)
                    idx = int(input("삭제할 번호: ")) - 1
                    if 0 <= idx < len(prompts):
                        deleted = prompts.pop(idx)
                        print(f"'{deleted['title']}'이 삭제되었습니다.")
                    else:
                        print("없는 번호입니다.")
        
                elif choice == "5":  # 종료
                    print("프로그램을 종료합니다.")
                    break 
        
                else:
                    print("잘못된 메뉴 번호입니다. 1~5 중에서 다시 선택해주세요.")
        
        if __name__ == "__main__":
            main()
        ```

        def select_category():

                        return get_non_empty_input("카테고리 직접 입력: ")

                    "category": "기타",
                    "favorite": False
                },

                    "favorite": False
                }

                if choice == "1":  # CREATE (프롬프트 추가)

                        "category": category,
                        "favorite": False

                    print("\n--- 현재 목록 ---")
                    for i, p in enumerate(prompts):
                        print(f"{i+1}. {p['title']} [{p['category']}]")
